## Changes
- Slack alerts: paste a Slack Incoming Webhook link in Settings → Slack alerts and Motio posts a message when a script or video waits for your approval, when a video is done (and whether Postiz took it) and when a video fails. It runs in the engine, so it also works while the app is closed if the engine runs on a server. "Send a test message" shows the real error when the link is wrong (#32).
- Release numbers now have a two-digit patch (v0.7.10) and every release page uses the same layout (#31).

## Verification
- GitHub CI passed on the pull request (engine tests on Ubuntu and Windows, desktop app build and clippy), and the release build passed on macOS and Windows.
- Automated tests: 321 passed locally on Linux with FFmpeg.
- Not tried yet: a real message to Slack (the build sandbox cannot reach hooks.slack.com) and the new Settings card in the packaged app.

- Windows x64: EXE or MSI installer.
