## Changes
- Fix: transcription failed in the installed Mac app with "Failed to load the default metallib", so no video could get past the Whisper step. The installer now carries the Metal library next to the library that loads it, and the build checks this on every release (#36).
- AI video: Projects → New video → AI video makes a French explainer from a topic with no source footage. Claude writes the scenes, an image model draws one picture per scene (Qwen-Image-2512 on fal by default), and the usual voice, captions and render put each picture under its line with a slow camera move. Pictures and prompts can be edited per scene in the project page, and Settings → AI pictures picks the provider. Videos made with a provider that is not cleared for monetized channels always stop at the video approval gate (#34).

## Known issue
- AI video: when the voice step rewrites or trims the script, the render can use the pictures of the old script. Re-rendering the project after editing a scene picture is not affected. The fix is a separate pull request that is not in this release.

## Verification
- GitHub CI passed on both pull requests (engine tests on Ubuntu and Windows, desktop app build and clippy), and the release build passed on macOS and Windows.
- The macOS build checks that `mlx.metallib` sits next to `libmlx.dylib` in the built app.
- Automated tests: 355 passed locally on Linux with FFmpeg.
