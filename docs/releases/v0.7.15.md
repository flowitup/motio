## Changes
- New look for the desktop app, "Studio" (design direction A of the design review, #53): a dark editing suite with a 76 px icon rail, a 56 px top bar, docked panels with hairline borders, LED-style status lights, and IBM Plex Sans / Mono with amber and cyan accents. The fonts are bundled inside the app (the app runs offline, so nothing is fetched from a font service); Geist is removed, and Chinese text keeps the system fonts. English and Vietnamese strings are in both catalogs.
- Trending is a score ledger with an inspector beside it. Projects has status filters with counts, with "Needs you" first, and 9:16 cards. The failed-project card shows only the failed step, because the project list does not carry the error text.
- New video is now its own page, `/projects/new`, with three tabs, instead of a card inside Projects.
- Project detail has three docked columns (monitor and sources, timed script with a timeline strip, review and post text) that stack into one page when the window is narrower than 1180 px. The player is a new custom one with a safe-area guide, a timecode and its own transport row. Line times and the timeline come from the last voice (`audio/narration.json`) when its texts equal the saved script; otherwise the times are estimates marked with `≈` and there is no timeline. The bars of the Voice track are drawn from the words' start times, not from real audio levels.
- Clips, Channels, Remove logo, Tools, Stats and Settings keep their layout and only get the new top bar and colours: the Studio colours replace the shadcn theme variables, so every page picks them up.
- Light mode is gone. The app is dark whatever the system setting is.
- The engine is not changed: no Python file other than the version number differs from 0.7.14.

## Verification
- Automated tests: 593 passed locally on Linux with FFmpeg on the release code, and 566 passed and 27 skipped with FFmpeg and ffprobe hidden, as on the CI runners; ruff clean; `pnpm build` succeeds and the built app contains the 15 IBM Plex font files and no link to an outside font host. GitHub CI passed on #53 and on the release pull request.
- Looked at before the merge (#53): Chromium screenshots of Trending, Projects, New video and Project detail at 1360 px and 1000 px, in English and Vietnamese, with no horizontal overflow.
- Not tried yet, and the main reason to look at this release first on the Mac: the app in a real Tauri window on macOS and on Windows (WebView), in particular playback of the finished H.264 video in the new custom player, the fonts inside the packaged app, and the narrow-window layout in the real window; `cargo clippy` was not run locally (CI runs it on every pull request); the packaged installers are built by the release workflow only after the tag; and the in-app update from 0.7.14 to 0.7.15. The pages other than Trending, Projects, New video and Project detail were only recoloured and were looked at less.

## Downloads
- macOS Apple Silicon: DMG installer.
- Windows x64: EXE or MSI installer.
- In-app updates use the signed update bundles and latest.json included in this release. The engine did not change in this release, so a remote engine (the Hetzner server, or the Windows PC) loses nothing by staying on 0.7.14; Settings → Engine status shows the version it reports (0.7.15 after a reinstall or deploy).
