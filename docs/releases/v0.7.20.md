## Changes
- **Kuaishou on the Trending screen** (#85). Trending has a new list, *Kuaishou · Featured*, that you follow like a Bilibili category. It reads Kuaishou's public Featured page: no login, no cookie, no signing. Each check shows a fresh selection of a few dozen videos of at least 15 s with a caption (it is a random draw of the home page, **not a ranking**, and has no categories; the screen says so). *Make video* downloads the video straight from the mp4 address the list gave, kept for 2 days in `data/cache/kuaishou_media.json`, so videodl is not needed for these. A pasted Kuaishou link still goes through videodl as before, and also when a saved address has expired. Kuaishou's search and detail queries need a browser cookie, so they are not read.
- **Choose which sources Trending fetches from** (#85). A *Fetch videos from* row at the top of Trending shows Bilibili and Kuaishou as switches, each with its count of new videos. A paused source keeps its list but is not checked and its videos are hidden. Switching on a source that has nothing followed yet follows its defaults (Bilibili: Tech, AI, AI film, Lifestyle; Kuaishou: Featured).
- Why only these two: Douyin, Weibo, Xiaohongshu, Xigua and Zhihu have no list a plain visitor can read (a login, a visitor cookie or a signed request is needed), so they stay paste-a-link. What was tried is in `docs/CN_PLATFORMS.md`.

## Before you use it
- **A remote engine has to be updated** (the Hetzner server and the Windows PC): the in-app update replaces only the engine inside the app, and the Kuaishou list and its *Fetch videos from* row call engine routes that an older engine does not have.
- Nothing needs to be set in `.env`. Kuaishou links you paste yourself still need `videodl` on the machine that runs the engine; the Featured list does not.

## Verification
- Automated tests on the release commit: **775 passed** with FFmpeg on PATH; `ruff check motio tests` clean; `pnpm build` succeeds. CI runs the tests without FFmpeg on Ubuntu and Windows, plus `cargo clippy`.
- On #85's branch the feed was read live from a cloud sandbox (28 videos) and one video was downloaded and probed (720x1280, 34 s).
- **Not tried:** the Trending screen and the source switches in the installed app, the Windows build, the Kuaishou list from the owner's own network (Kuaishou may answer differently from a home connection), and everything listed as not tried in v0.7.19 that has not been checked since (whole-video dub with real ElevenLabs and Claude, logged-in cookies, the in-app update from 0.7.19).
- **Known limits, left for a later release:** the list is a random draw, so a video seen once may not come back; Trending still shows "Checking…" until every category has answered; a download that stopped half way can leave a stale `.part` file; the 0.7.17 leftovers (Anthropic workspace ID setting, ElevenLabs voice list message).
- **Not in this release:** the AI video length picker (#79) and the removal of the daily video cap, source credits and `NEWS_SOURCES` (#78) are still open pull requests.
