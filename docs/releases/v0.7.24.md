## Changes
- **Keyword filter on the Scan screen** (#97). The Scan form has a new optional *Keyword filter* box. The videos are read first, as before (the number set under *Videos per line*), and then only those whose title or account name holds every word you typed are kept (not case sensitive). The status line says how many of the videos read matched, for example "Done: 4 of 20 videos read have "street food" in the title", so an empty table tells you "nothing matched" apart from "nothing found". The filter works for every platform and mode, and is also kept when a scan is reopened. The filter is applied after reading, so a narrow keyword on a short list can match few or no videos; raise the number of videos per line to widen it. Nothing is saved or made by a scan.

## Before you use it
- **A remote engine has to be updated** (the Hetzner server and the Windows PC): the in-app update replaces only the engine inside the app, and the keyword box is filtered by the engine, so an older engine ignores it. Settings > Engine status shows the engine's version.
- Everything in v0.7.23 still applies (Google Drive needs its one-time setup; the Douyin no-account search needs Chrome, Chromium or Edge on the machine that runs the engine).
