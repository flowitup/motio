## Changes
- **New: Review queue** (#105). When something waits for you, Projects shows an amber *Review queue (n)* button on top. It opens one screen with every script, picture set and video stopped at a channel's approval gate, oldest first: the script or the video with its post text and quality check on the right, the list on the left. Keys: **A** approve, **S** approve a video without sending it, **J** / **K** (or the arrows) next / previous, **O** or Enter open the project, space play / pause. *Approve n scripts* approves every waiting script in one go, after a confirmation. A video that would be posted publicly right away asks before it is sent. Pictures of an AI video are still approved one by one on the project page.
- **New: make videos automatically from new videos** (#105). A channel's *Make videos automatically* section has a new choice, *From new videos (Trending and Followed)*: *Off* (default), *Explainer* or *French dub*. When it is on, after each scheduled refresh and each scheduled check of the followed sources, new videos scored at or above the channel's minimum score become videos for that channel, best score first, within its *Videos per day* and the monthly budget. Only videos first seen in the last 24 hours count, so turning it on does not go back through old ones. Until now this section only made videos from news topics, which are off by default, so it made nothing. The channel form says so when both are off.
- **Fix: sending again after a partial Postiz send no longer posts twice** (#105). When a video went to some Postiz channels and failed for the others (for example the 16:9 copy), *Send again* used to send to all of them, so the channels that already had it got a second post. Motio now remembers which channels are left and sends only to those, at the posting time already chosen if it is still ahead.
- **Fix: a transcription that hangs no longer blocks every other video** (#105). The engine makes one video at a time, and a stuck Whisper run held that place for good. A transcription now has a time limit (1 hour plus 10 s per second of sound); past it the project fails with a message that says to restart Motio and continue. On Windows and Linux (faster-whisper) the model is also kept in memory between videos instead of being loaded again each time.
- Releases: merging a version change to `master` now creates the tag and starts the installer build by itself (#104). This is the first release made that way. Publishing the draft is still done by hand.

## Before you use it
- **Review queue:** Projects > *Review queue (n)*. The button only shows when something is waiting. Approving a script uses voice credits, as on the project page.
- **Automatic videos from new videos:** Channels > edit a channel > *Make videos automatically* > set the minimum score and *Videos per day*, then pick *Explainer* or *French dub* under *From new videos*. It needs *Auto refresh* in Settings. Each video costs Claude and voice credits, and it still stops at the channel's approval gates. It stays off until you turn it on.
- **A remote engine has to be updated** (the Hetzner server and the Windows PC): the in-app update replaces only the engine inside the app, and the fixes and the automatic videos live in the engine. An older engine ignores *From new videos*. Settings > Engine status shows the engine's version.
- v0.7.25 (Clip mode) was built but its release was still a draft when this one was made: everything in its notes applies to this version too, along with v0.7.23 and v0.7.24.
